# v2 검토용 묶음 4/7

(v2-devices · v2-devices-2 · v2-walkthrough · v2-rollout를 순서대로 이어 붙여 나눈 것. 정의는 묶음 1의 §정의.)

- **불안정**: 같은 실행 전 지문으로 여러 번(설정값) 돌려 갈릴 때만. ⑦을 막고 시험자에게.
- **⓪ 시험 등록**: 시험자가 케이스를 쓰고 시험대 실행 요청으로 실패 기록을 남겨야 ①. 자동 재현 불가는 대표가 고르면 수동 케이스(캡처 전후·검토자 판정 줄·파일 경로 패턴)로 등록.

## 되돌림 두 가지

- **검토 불통과**: ⑥ → ⑤(검토 항목 번호별), 구현자 쓰기 창 다시 열림. 바퀴 상한, 2연속이면 다른 계열 1회.
- **명령 오류**: 구현자 표시 + 시험자 확인 → ⑤ → ③. 계획자가 plan.md, 시험자가 다음 번호 스크립트. 되돌림 상한.

## 작업 사본 합치기 (직원별 사본 모드)

훅 입력에 직원 식별이 없는 모드에서는 칸 경계마다 처리기가 각 사본을 기준 트리로 합친다. 검사는 **충돌 0, 사본별 허용 밖 변경 0**. 충돌이면 풀지 않고 멈춘다.

## 상한값·역할 구분

- 호출·바퀴·되돌림·시간·소형 파일 수·불안정 반복 수·요청 처리 시간 상한은 설정에, 바꾼 날과 이유를 적는다.
- 직원 식별이 훅 입력에 들어오는지 첫 시험에서 확인, 없으면 직원별 사본 모드.

## 보호 파일 목록

| 부류 | 파일 | 왜 |
|---|---|---|
| 장치 기록 | 프로젝트 `state/` `records/` `일지.jsonl` `archive/` | 상태·번호·케이스 수·대표 입력 근거·보관본 |
| 장치 기록 | 일 폴더 `records/`(요청 결과·probe 로그 포함) `gates/` `snapshots/` | 검사 근거·시험 결과·복원 기준 |
| 장치 기록 | `.git/` 전체 | 훅 경로·가지 위치 |
| 설정 | 설정 파일(임계값·훅별 모드·제외 목록·적용 목록·배포 산출물 경로·고지 예외·공개용 신원·허용 목록·금지 목록) | 느슨하게 고치면 모든 관문이 느슨해진다 |
| 설정 | 훅 스크립트 폴더, 훅 등록 전역 설정, 설치 폴더, 프로젝트 `.claude/`, 서버 쪽 검사 설정 | 훅을 고치거나 끄는 자리 |
| 설정 | 도면, **모든 깊이의 `.gitignore`(새 파일 포함)** | 케이스 정리 근거 / 커밋 범위를 바꾸는 자리 |
| 소유 불가 | 의존성 폴더, manifest·잠금 파일(설치 요청으로만), 시험 설정·`conftest.py`, 링크 파일, 하위 저장소, 작업 트리 밖 비밀·운영 키(읽기도 거부) | 시험 결과·범위·외부 호출을 바꾸는 자리 |

## 첫 시험에서 확인할 항목 (확인 전까지 "추정")

1. 훅 입력에 직원 식별이 들어오는가.
2. 실행기·설치·probe가 전용 샌드박스에서 돌고 처리기는 결과만 읽는가. 설치 스크립트·플러그인 자동 로드 꺼짐.
3. 모델 호출 금지 설정이 대표 입력 명령 전부에서 작동하는가.
4. 칸마다: 보호 경로 쓰기 거부, 운영 키 읽기 거부, 허용 외 주소 차단, 설치본 지문 = 고정 버전, **닫힌 쓰기 창의 직원이 자기 파일도 못 쓰는가**.
5. 실행기가 프로젝트 시험 설정·conftest·플러그인을 읽지 않는가.
6. 메일·문자 시험 모드/중계가 수신처를 강제하는가.
7. 실행 사본에서 돌린 뒤 원본 지문 그대로인가. 무시 파일에 기대는 코드가 사본에서 실패로 드러나는가.
8. 임시 인덱스 `git commit`에서 pre-commit이 실제로 도는가.
9. **오래 걸리는 요청**(전체 시험대·설치)이 훅 시간 제한과 무관하게 처리기에서 끝나는가.
10. 뚫리는 장면 재현: 상태 파일 손상 / 옛 bench.json으로 커밋 / `conftest.py` 새 파일 / 변수 접두 / `git -c`·`--config-env` / `claude` 재호출 / 대기 줄 위조 / 허용 명령 뒤 출력 돌림 쓰기 / 맨 위 `.gitignore` 한 줄 추가 / **하위 폴더에 새 `.gitignore`** / **작업 트리 밖을 가리키는 링크 파일** / 전역 무시 설정이 다른 두 컴퓨터에서 지문 비교 / **대기열에 옛 지적이 있는데 복구 직후 새 지적** / **커밋 뒤 닫았을 때 보관본이 비어 있는가** / **⑥ 통과 뒤 구현자가 파일을 고치고 커밋 요청** / **대소문자만 다른 결과 파일 이름** / 설치 요청 전 허용 밖 변경을 남겨 두기 / design 폴더의 다른 파일을 "이거다" 뒤에 고치기.

# IF 공방 v2 — 흐름 한 바퀴와 우회 대조

규칙을 고칠 때마다 이 문서를 처음부터 다시 따라간다. 멈추는 곳이나 뚫리는 곳이 나오면 규칙이 틀린 것이다. 정의는 `v2-devices.md` §정의. 자리 표시는 {이름}.

## 정상 흐름 한 바퀴

| 칸 | 누가 | 무엇을 어디에 쓰나 | 검사가 무엇과 대조하나 | 막힐 수 있던 곳 → 해결 |
|---|---|---|---|---|
| 일 열기 | 대표 `/일` 또는 `지적`(「닫힘」이면 즉시, 가장 작은 번호, 이름 `지적-{번호}`) | 훅이 상태를 「열림」으로, 처리기가 일 폴더·일 시작 사본 | 대표 입력인지, 상태 「닫힘」인지, 대기열, 같은 이름 일 폴더 없음 | 「복구 중」에 지적이 오면 더러운 트리로 열림 → 복구 중에는 대기열에만 |
| ⓪ 시험 등록(지적 일) | 시험자 | `tests/bench/{다음 번호}`; 시험대 실행 요청 → 처리기가 실행 사본에서 실패 기록 | 실행 전 지문 = 지금 지문 | 요청을 훅이 처리하면 시간 제한 → 처리기 |
| ① 사실확정 | 사실확정자(쓰기 창 ①) | `outputs/facts.md` | 통과 줄 출처 ∈ 열람 기록, 확인 필요 0 | — |
| ② 실측 | 실측자(쓰기 창 ②; 소형 궤도면 계획자가 ③에서) | `scripts/probe/{대상}` 스크립트; **실측 실행 요청** → 처리기가 실행 사본에서 돌려 로그를 `records/probe/`에 | probe 키 = facts 키 | 로그가 작업 트리에 남아 범위에 들어감 → 기록으로 옮김 |
| ③ 계획 | 계획자 / 시험자 | `outputs/plan.md`·`outputs/tools.md` / `tests/bench/scenes/{다음 번호}` | 소유 겹침 0, 공용 파일 배정, 소유 불가 파일 미배정 | manifest 주인 한 명 → manifest는 소유 불가, 설치 요청으로 |
| ④ 시안 | 시안자(쓰기 창 ④) | `outputs/design/` | "이거다"(대표 입력) 번호 > 제시 줄 번호, 제시 줄 해시(design 폴더 전체) = 지금 해시 | 파일 하나 해시면 다른 파일이 승인 없이 들어감 → 폴더 해시 |
| ⑤ 구현 | 구현자(쓰기 창 ⑤, 소유표 = 샌드박스 허용) | 배정된 파일, `outputs/coverage-{구현자}.md`, 요청(장면 실행·설치) | 입구에서 design 해시 재대조; 장면 실행 기록; 명령 뒤·칸 끝 비교; 커밋 트리 vs HEAD 재판정 | 설치가 허용 밖 변경을 흡수 → 설치 전 비교 0 확인 뒤 새 사본 |
| ⑥ 검토 | 검토자(일회용 사본) → 처리기 | `outputs/review.md`; 처리기가 **검토 지문**을 `gates/`에 | coverage 근거, ⓪ 재현, scenes 편집 기록, 사본 지문 = 원본, 검토 항목 번호 | 구현자가 ⑥ 뒤에 고침 → 쓰기 창 닫힘 |
| ⑦ 시험대 | 처리기(실행 사본) | `gates/bench.json`(pass, **시험대 지문**, 케이스 수) | 케이스 수 ≥ 프로젝트 `state/` 마지막 케이스 수, 불안정 0 | 새 일에 비교값 없음 → 프로젝트 state |
| 커밋 | 처리기, ⑦ 통과 직후 스스로 | 임시 인덱스 `git commit`(pre-commit은 처리기 커밋만 통과) | **검토 지문 = 시험대 지문 = 지금 지문**; 다르면 멈추고 대표가 ⑦ 사본 복원 또는 지금 트리 수용(⑥부터) | ⑥ 뒤 지문이 바뀌면 장치 밖 변경 → 자동으로 ⑥에 넘기지 않음 |
| 배포 | 처리기 + 서버 쪽 검사 | 실행 사본에서 빌드, 산출물 경로만 따로 커밋(pre-commit 통과 조건 (나)) | 산출물 경로를 뺀 지문 = 시험대 지문, 바뀐 경로는 산출물 경로 안만, 교차 점검 도착 | 빌드 뒤 지문이 달라 관문에 걸림 → 배포 관문 별도 |
