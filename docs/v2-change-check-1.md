## docs/v2-devices.md
이전: | **보관** | 닫기·포기 때 처리기가 **마지막 커밋(HEAD)과 지금 트리의 차이**만 `projects/{프로젝트}/archive/{일 이름}/{시각}/`에 보관하고, 보관이 실패하면 「열림」에 머물고 멈춘다. 보관이 성공하면 상태는 「닫는 중」이 되고 마무리는 보관 → 「닫는 중」 → HEAD 맞춤 → 미뤄 둔 승인 커밋 → 트리 = HEAD 재확인 → 「닫힘」 → 대기열 순서다. 재확인에서 트리가 HEAD와 다르면(예: `.gitignore` 변경으로 무시되던 파일이 범위에 들어옴) 「닫는 중」에 멈추고 대표에게 알린다. 그 뒤 어느 단계가 실패해도 「닫는 중」에 머문다. 차이는 커밋 트리 범위 안에서 재고, HEAD에 없는 새 파일도 보관한 뒤 지우며, 무시 파일과 제외 목록 경로는 건드리지 않는다. 커밋된 내용은 닫기가 건드리지 않는다. 보관본 삭제는 대표만 |
이후: | **보관** | 닫기·포기 때 처리기가 **마지막 커밋(HEAD)과 지금 트리의 차이**만 `projects/{프로젝트}/archive/{일 이름}/{시각}/`에 보관하고, 닫기·포기를 받으면 처리기가 **먼저 상태를 「닫는 중」으로 바꾸고**(직원 쓰기가 끼어들 틈을 없앤다) 보관한다. 마무리는 「닫는 중」 → 보관(실패면 원래 상태로 되돌리고 멈춤) → HEAD 맞춤 → 미뤄 둔 승인 적용·커밋 → 트리 = HEAD 재확인 → 「닫힘」 → 대기열 순서다. 보관이 실패하면 상태를 원래대로(「열림」이면 「열림」, 「복구 중」이면 「복구 중」) 되돌리고 멈춘다. 재확인에서 트리가 HEAD와 다르면(예: `.gitignore` 변경으로 무시되던 파일이 범위에 들어옴) 「닫는 중」에 멈추고 대표에게 알린다. 보관 뒤 어느 단계가 실패해도 「닫는 중」에 머문다. 차이는 커밋 트리 범위 안에서 재고, HEAD에 없는 새 파일도 보관한 뒤 지우며, 무시 파일과 제외 목록 경로는 건드리지 않는다. 커밋된 내용은 닫기가 건드리지 않는다. 보관본 삭제는 대표만 |
