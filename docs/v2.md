# IF 공방 v2 — 절차가 코드가 되고, AI는 한 칸만 맡는다

v1은 부품 9개와 다듬질 고리를 정했다(`concept.md`). v2는 그 위에 한 가지를 더 고정한다:
**절차를 지시문으로 두지 않고 장치로 만든다.** 반장(메인 에이전트)이 절차를 수행하는 주체에서
내려오고, 절차는 코드로 정해진 궤도가 되며, AI 직원들은 궤도의 한 칸씩만 맡는다.

v2가 약속하는 것은 오류 0이 아니라 **오류의 재발 0**이다. 처음 보는 오류는 사람 눈이 아니라
미리보기·검토자·시험대에서 걸리고, 그 지적이 시험 케이스가 되어 두 번째는 없다.

## 왜 장치인가

AI 에이전트에게 글로 적은 규칙("이 단계에서는 이 스킬을 쓴다")은 에이전트가 스스로 기억하고 선택해야
작동한다. 문맥이 커지고 일이 급해지면 선택은 습관(터미널 명령으로 직접 처리)으로 돌아가고, 안내만
하는 훅은 무시된다. 반면 **막는** 훅(승인 관문, 위험 명령 차단)은 지켜진다. v2는 그 차이 위에
서 있다. 지켜야 할 것은 지킬 필요가 없게(주입·화이트리스트·순서 고정) 만들고, 산출물이 없으면 다음
행동을 막는다.

## 궤도 9칸

일 하나 = 폴더 하나 = 대화창 하나. 산출물은 전부 그 폴더의 파일이고, 다음 칸은 **코드가 파일을
검사해서** 연다. 모델이 순서를 정하지 않는다.

| 칸 | 맡는 직원 | 받는 것 | 내는 것(파일) | 도구 화이트리스트 | 다음 칸이 열리는 조건 |
|---|---|---|---|---|---|
| ⓪ 시험 등록 (지적에서 시작한 일만) | 시험자 | 대표 지적(작업 일지) | `tests/bench/`에 케이스 + **현재 코드에서 실패한 실행 기록** | 읽기, 쓰기(`tests/bench/`만), 터미널(샌드박스) | 실패 기록이 있어야 ①로. 이 칸도 칸 끝 해시 비교를 받는다 |
| ① 사실확정 | 사실확정자 | 지시 한 줄 + 자동 주입(곳간 검색 결과·그 프로젝트 작업 일지·도면·방향 원문표) | `facts.md` — 주장별 통과/확인 필요/탈락 + 출처. 「코드에 넣는 값」표는 `키 | 값 | 판정 | 출처` 고정 형식, 키는 `{대상}.{필드}` | 읽기, 검색, 곳간, 웹 문서 읽기, 스킬, **쓰기는 `facts.md` 한 파일만**. 터미널 없음 | 「코드에 넣는 값」표에 「확인 필요」가 0개 **이고 「통과」 줄마다 출처가 있을 것**(출처 없는 통과는 막힘). ② 실측 응답과 값이 다르면 되돌아옴 |
| ② 실측 | 실측자 | facts.md의 외부 대상 목록 | `probe/{대상}.log` — 공식 문서 주소, 실제 호출 1회(**조회·테스트 모드만**), 성공 표시, 실제 요청·응답 형식, 그리고 `{"{대상}.{필드}": 값}` 블록 — facts.md와 **같은 키**로 스크립트가 대조 | 읽기, 쓰기(probe/만), 터미널(샌드박스), 웹 문서 읽기 — **운영 키 없음**(이것이 외부 쓰기를 막는 벽) | 대상마다 성공 표시. 쓰기 성격(게시·발송·결제·삭제) 호출은 승인 관문 + 테스트 계정으로만 |
| ③ 계획 | 계획자 | facts·probe | `plan.md`(통과 장면: 사람이 하는 일 → 앱이 보여 주는 결과 → 화면 위치 → **그 장면을 돌리는 스크립트 이름** — 스크립트는 `tests/bench/scenes/`에 시험자가 만들고 고친다 — 시험자이면서 ③ 칸이거나 「명령 오류」로 되돌아온 중일 때만, 고친 이력은 ⑥ 대조 항목 — 구현자는 손댈 수 없으며, `package.json` 같은 구현자 소유 파일을 경유하지 않는다, 예외 장면, 파일 소유), `tools.md`(이 일의 도구표) | 읽기, 검색, 스킬(계획·육칠·스킬 창고 검색), 곳간, **쓰기는 `plan.md`·`tools.md`만**. 터미널 없음 | plan.md + tools.md. 갈림길이면 육칠 채점표에 대표 선택 인용 |
| ④ 시안 | 시안자 | plan.md(화면 일만) | `outputs/design/` 폴더(대표 파일 `design.md`) — 분위기 한 문장·서체 2·색 2·그리드·**참고 제품 캡처**·구조 옮김표·시안 링크·**대표 "이거다" 원문** | 읽기, 쓰기(**`design/`·시안 파일 폴더만**), 스킬(아우라 파밍·레이아웃), 브라우저, 시안 도구 | "이거다" 인용이 있어야 ⑤ 열림 |
| ⑤ 구현 | 구현자(파일 소유별로 여러 명 동시) | plan·facts·probe·design | 커밋 없음(커밋은 처리기가 ⑦ 통과 직후 검토·시험대·지금 세 지문이 같을 때 침 — 직원은 `git commit`을 직접 못 침, `v2-devices.md` §정의 「세 지문」), plan.md의 통과 장면 스크립트 실행 기록(**구현자가 명령을 고르지도 바꾸지도 못한다**; 스크립트가 틀렸으면 「명령 오류」 표시 → ③으로 되돌아가 계획자·시험자가 고침, 이 되돌림은 바퀴 상한과 따로 셈), `coverage-{구현자}.md` 대조표 초안(궤도 스크립트가 합침)(자료·벤치마킹 항목별 들어감/일부/빠짐 + 파일:줄·캡처) | 읽기, 편집, 쓰기(**`tests/bench/` 차단**), 터미널(배포·DB·설치·push 차단), 스킬. **작업조 생성 없음** | 값싼 통과 장면 스크립트의 **실행 기록**(종료 코드 0, 마지막 편집 뒤)이 있을 것. 그리고 ⑤가 끝날 때 **실제 변경분**(파일 수·경로)으로 승격 판정을 한 번 더 돌려, 걸리면 소형 궤도를 전체 궤도로 되돌림 |
| ⑥ 검토 | 검토자 | 결과물·코드·통과 장면 | `review.md` — `판정: 통과/불통과`, 통과 장면 대조, **합친 coverage의 "들어감"을 근거를 열어 하나씩 확인한 표**, 지적에서 시작한 일이면 **"⓪ 케이스가 지적 원문의 현상을 재현하는가"** 한 줄, `scenes/`가 고쳐졌으면 그 이력 대조, 지적(번호·심각도·파일:줄·실패 장면), 화면이면 품질 판정표, 실제로 돌려 본 것 | 읽기, 검색, 브라우저, 터미널 — **일회용 작업 사본**(쓰기 허용, 칸 끝에 통째로 폐기)에서만. 원본 쪽 쓰기는 `review.md` 한 파일만 | 판정: 통과, 그리고 궤도 스크립트가 적은 **지문**(커밋 트리 범위, `v2-devices.md` §정의)이 지금 지문과 같을 것. 불통과면 ⑤로(바퀴 상한, 넘으면 멈추고 대표에게) |
| ⑦ 시험대 | 없음(스크립트) | 프로젝트의 `tests/bench/` | `bench.json`(일 폴더 `gates/`, 작업 트리 밖) — pass/fail, 케이스별 점수, ⓪에서 등록한 케이스의 **고친 뒤 통과 기록** | — | pass:true, 그리고 검토 지문·시험대 지문·지금 지문이 같을 것(다르면 커밋하지 않고 멈춤, `v2-devices.md` 「세 지문과 커밋」). 민감 영역 기준에 걸리면 다른 계열 읽기 전용 점검 1회 추가 |
| ⑧ 보고 | 반장 | 위 전부 + 계기판 | `report.md` — ⑥이 확인한 대조표(⑤의 초안 중 검토자가 근거를 연 항목만 "들어감") · 화면 · 숫자 · 실측 · 미검증 · 도구표 대조 | — | 이 절들이 있고, 「실측」 절의 명령이 **훅의 실행 기록에 실제로 있어야 일 닫기 스크립트가 통과**한다("완료"라는 말은 검사하지 않는다 — 일이 열려 있는 동안 답 끝에 상태 줄이 자동으로 붙는다). 대조표는 ⑥ 확인본을 그대로 옮기며, ⑧에서 새로 "들어감"을 적을 수 없다 |

- **소형 궤도**(문구·버그 1개): ①②③을 한 파일 `outputs/plan.md`로 줄인다(주인 계획자, 쓰기 창 ③, 사실확정·실측 내용은 그 파일 안의 절 — ①②는 따로 열리지 않고 probe 쓰기·실측 요청도 계획자가 ③에서). ⑥·⑦은 건너뛰지 않으며 커밋 조건도 같다. ⑤ 끝 재판정에서 전체 궤도로 올라가면 구현 결과와 plan.md를 보관하고 비운 뒤 HEAD로 맞추고 ①부터 다시 연다(보관한 plan.md는 사실확정자가 읽기만). 소형인지는 대표가 `/일`에서 고르고, 계획의 파일 수가 설정값을 넘거나 **민감 영역**을 건드리면 **코드가 전체 궤도로 자동 승격**하고 막는다 — AI가 고르지 않는다. 민감 영역은 계획자의 글이 아니라 설정 파일의 **대조 가능한 기준**으로 판정한다: 경로 패턴(`auth/`, `login`, `oauth`, `payment`, `billing`, `publish`, `deploy`, `migrations/`, `.env`, `settings`, 그리고 **장치 자체를 끌 수 있는 파일**: CI 설정(`.github/workflows` 등), `.claude/`, 훅 스크립트, `package.json`의 `scripts`), 패키지 목록의 변화, 변경분에 새로 들어온 외부 호출 주소(127.0.0.1 밖의 `http(s)://`), 서비스·크론 명령. ⑦에서 다른 계열 점검을 붙일지도 같은 기준으로 코드가 정한다.
- **건너뛰기**는 대표만: `건너뛰기 {칸} {이유}` 한 줄이 상태에 남고 보고에 찍힌다.
- **멈출 조건:** 같은 지적이 두 바퀴 뒤에도 남음 / 가설 셋이 틀림 / 바퀴 상한 → 멈추고 "무엇을 해
  봤고 왜 멈췄는지" 보고한 뒤 범위를 줄인다.
