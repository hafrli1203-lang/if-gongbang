## 울타리 — 막는 훅 (단일 기준표)

| 훅 | 언제 | 무엇을 하나 |
|---|---|---|
| 일 열기 | `/일 {이름}` — 대표 입력만 | 상태가 「닫힘」이 아니면 거부. 대기열이 비어 있지 않으면 거부(지적부터). 같은 이름의 일 폴더가 이미 있으면 거부. 「열림」으로, 일 폴더 생성, 처리기가 일 시작 사본, ① 칸 |
| 지적 | `지적 {내용}` — 대표 입력만 | 원문 기록에 번호로 남고 대기열에 들어간다. 「닫힘」이면 처리기가 **대기열의 가장 작은 번호**로 `지적-{번호}` 일을 ⓪ 칸으로 즉시 연다. 「열림」·「복구 중」이면 대기열에만 |
| 이거다 · 채점 | `이거다 {시안 파일}` 등 — 대표 입력만 | 원문 기록에 번호로. 제시 줄보다 뒤이고 그 제시 줄의 design 폴더 해시가 지금 해시와 같을 때만 ④ 통과. ⑤ 입구에서 다시 대조 |
| 일 닫기·포기·복구 | `일 닫기 {이름}`, `포기 {이름} {사유} {다시 넣기 또는 버리기}`, `일 복구 {프로젝트} {일 이름}` — 대표 입력만 | 닫기 = ⑧까지 간 일, 포기 = 중간 종료(승인). 둘 다 처리기가 **HEAD와 지금 트리의 차이만** `archive/{일 이름}/{시각}/`에 보관 → HEAD로 맞춤 → 미뤄 둔 승인 적용·커밋 순으로 끝낸 뒤 대기열을 연다(어느 단계든 실패면 멈추고 대표에게, 대기열은 열지 않음). 마지막 처리 번호는 §정의 규칙. `/일`로 연 일의 포기는 선택 없이 받는다. 복구 = 상태 파일이 읽히면 거부, 그 이름의 일 폴더가 있고 보관본이 없을 때만 「복구 중 {일 이름}」으로 만든다. 그 뒤 닫기는 ⑧ 통과 기록이 있을 때만, 없으면 포기만. 닫기·포기 뒤 대기열이 있으면 가장 작은 번호로 ⓪ 일 |
| 편집 | 편집·쓰기 도구 | 「산출물 주인」 × 「쓰기 창」(§정의). 추가 조건: `tests/bench/` 케이스 본체 = 시험자 ∧ ⓪ ∧ 다음 번호; `tests/bench/scenes/` = 시험자 ∧ (③ 또는 명령 오류 되돌림) ∧ 다음 번호; `outputs/plan.md` = 계획자 ∧ (③ 또는 명령 오류 되돌림); 작업 트리 코드 파일 = 소유표에서 그 파일을 배정받은 구현자 ∧ ⑤. 소유 불가 파일·보호 파일은 누구도 못 씀. 일지는 요청으로만 |
| 요청 | `requests/{직원}/{번호}.md` 쓰기 → 훅이 접수 기록 → 처리기가 처리 | 장면 실행: 구현자(⑤)·시험자(⓪·③) / 시험대 실행: **⓪ 실패 기록용으로 시험자만**(⑦은 처리기가 스스로 하며 직원 요청으로 받지 않음) / **실측 실행**: 실측자(②) — probe 스크립트를 실행 사본에서 돌리고 로그는 `records/probe/`로 / 설치(이름·버전): 구현자(⑤) — §정의 「설치」 / 일지 덧붙이기: 반장·검토자. 커밋은 요청이 아니다(커밋 훅 행). 결과는 `records/requests/{직원}/{번호}.result`와 실행 기록 |
| 터미널 | 직원의 터미널 명령 | 연결 기호(세미콜론, 이중 앰퍼샌드, 이중 수직선, 앰퍼샌드, 수직선, 출력 돌림과 덧붙임 돌림, 달러 괄호, 백틱, 줄바꿈, 입력 돌림 괄호, 히어독) 단위로 쪼개 허용 목록과 대조, 쪼갤 수 없으면 거부. 명령 앞 변수 대입 전부 불허. `git` 바로 뒤 옵션 전부 불허, `--no-verify` 불허. 목록에 없는 것: claude, bash -c, sh -c, xargs, find -exec, env, eval, exec, ln, git commit, git push, git submodule, 패키지 설치 명령, 시험 실행기. 명령 뒤 칸 시작 사본과 비교해 복원. 벽은 샌드박스 |
| 커밋 | ⑦ 통과 직후 처리기가 스스로 | 검토 지문 = 시험대 지문 = 지금 지문일 때만, 임시 인덱스 `git commit`. 다르면 커밋하지 않고 멈춘다 — 대표가 (가) ⑦ 칸 시작 사본 복원 후 ⑦부터 (나) 지금 트리 수용 후 ⑥부터 중 선택. 일이 열린 동안 pre-commit은 처리기의 커밋 둘(세 지문 커밋, 배포 산출물 커밋 — 「대표 터미널」)만 통과, 대표의 직접 커밋 거부 |
| 배포 | 배포 스크립트 + 서버 쪽 검사 | 산출물 경로를 뺀 지금 지문 = 시험대 지문, 교차 점검 결과 도착 전엔 차단. 빌드는 처리기가 실행 사본에서, 산출물은 따로 커밋 |
| 공개 저장소 push | `git push`(AI 쪽)와 git pre-push 훅 | 원격에 없는 모든 커밋의 파일 내용·경로·메시지·꼬리말·브랜치·태그·이미지와 문서 메타데이터를 금지 목록으로. 신원은 공개용 고정값만. 고지 예외는 문단 단위 |
| 작업조 | 작업조 생성 | ⑤⑥에서 역할 직원이 아닌 범용 작업조 거부 |
| 상태 줄 | 답이 끝날 때 | 일이 열려 있으면 "현재 칸 ④ · 미검증" 줄 자동 부착 |
| 반장 터미널 | 일이 열린 동안 | 반장 터미널 전부 거부, 호출 수 초과 거부 |
| 승인 범위 | `승인 {이름}` | 열린 일·프로젝트와 이름이 맞지 않으면 거절. 배포·삭제는 짧은 창 |
| v1 유지 | — | 승인 관문, 위험 명령, 비밀 파일, 훅 자체 보호 |

## 상태·대표 입력·대기열

- 상태·마지막 처리 번호·마지막 케이스 수·queue.md·원문 기록은 프로젝트 폴더에 있어 일이 없어도 존재한다. 적용 목록 프로젝트는 상태 파일이 없거나 못 읽으면 **일 복구를 뺀 모든 v2 훅과 처리기 작업을 거부**한다.
- 대표 입력만 인정하는 명령: `/일`, `지적`, `이거다`, 채점 선택, `일 닫기`, `포기`, `일 복구`, `승인`. 「닫힘」에서 깨어 있는 훅은 이 가운데 일 열기·지적·일 복구와 상주 처리기. 명령 파일에 모델 호출 금지 설정, 훅이 원문 기록으로 대표 입력인지 확인.
- 대기열 = 원문 기록의 `지적` 중 번호 > 마지막 처리 번호, 가장 작은 번호부터. 표시 `queue.md`는 훅이 만든다. `/일`은 대기열이 비어 있을 때만.

## 케이스 관리

- 두 종류: **지적 케이스**(⓪, 실패→통과)와 **장면 케이스**(③ 장면 스크립트, ⑦ 통과 기록). 수는 따로 세고 **이전 값은 프로젝트 `state/`의 마지막 케이스 수**(⑦ 통과 때 처리기가 갱신).
- 이름은 다음 번호만. 실행기는 번호 형식 파일만 모은다.
- 실행기는 하네스 고정 설정으로 전용 샌드박스에서: 프로젝트 시험 설정·`conftest.py` 무시(pytest는 `--noconftest -c {하네스 설정}`), 플러그인 자동 로드 끔.
- **케이스 교체**: 새 번호가 옛 번호를 "대체"로 가리키고 실패 기록을 이어받는다. 승인 번호와 묶이고 수에서 줄지 않는다.
- 케이스마다 출처 지적 번호와 묶인 도면. 수가 줄면 실패(승인 번호와 맞는 정리·교체만 예외).
- **불안정**: 같은 실행 전 지문으로 여러 번(설정값) 돌려 갈릴 때만. ⑦을 막고 시험자에게.
- **⓪ 시험 등록**: 시험자가 케이스를 쓰고 시험대 실행 요청으로 실패 기록을 남겨야 ①. 자동 재현 불가는 대표가 고르면 수동 케이스(캡처 전후·검토자 판정 줄·파일 경로 패턴)로 등록.

## 되돌림 두 가지

- **검토 불통과**: ⑥ → ⑤(검토 항목 번호별), 구현자 쓰기 창 다시 열림. 바퀴 상한, 2연속이면 다른 계열 1회.
- **명령 오류**: 구현자 표시 + 시험자 확인 → ⑤ → ③. 계획자가 plan.md, 시험자가 다음 번호 스크립트. 되돌림 상한.

## 작업 사본 합치기 (직원별 사본 모드)

훅 입력에 직원 식별이 없는 모드에서는 칸 경계마다 처리기가 각 사본을 기준 트리로 합친다. 검사는 **충돌 0, 사본별 허용 밖 변경 0**. 충돌이면 풀지 않고 멈춘다.
