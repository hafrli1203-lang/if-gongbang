# IF 공방 v2 — 장치 1: 정의와 검사

`v2.md`의 궤도 표와 직원 표가 "무엇을 막는가"라면, 이 문서는 "어떻게 막는가"다. 원칙은 하나: **AI가 적은 글을 믿지 않고, 훅이 따로 남긴 기록과 대조한다.** 여러 곳에서 쓰는 정의는 **이 문서 §정의에만** 두고, 다른 문서는 여기를 가리킨다. 자리 표시는 {이름}처럼 중괄호로 쓴다.

모형은 다섯 줄이다. ① 장치가 쓰는 것과 비밀은 작업 트리 밖. 프로젝트 단위와 일 단위를 가른다. ② 범위는 하나 — **커밋 트리 범위**. 지문·사본·실행·검토·비교·복원이 전부 이 범위. ③ 직원이 장치에 시키는 일은 **요청** 한 길. 훅은 접수만 하고 **상주 처리기**가 처리한다. ④ 쓰기 권한은 칸에 묶인다 — 구현자는 ⑤에서만 쓴다. ⑤ 관문은 둘 — 커밋 관문(검토·시험대·지금 세 지문 일치)과 배포 관문.

## 정의 (단일 출처)

| 용어 | 정의 |
|---|---|
| **작업 트리** | 프로젝트 폴더. 코드·`tests/bench/`·`scripts/probe/`·추적 설정만. **비밀 파일·운영 키·장치 기록·일 산출물은 안에 두지 않는다.** 샌드박스에는 테스트 값이 환경으로 주입된다 |
| **하네스 홈** | 작업 트리 밖. 프로젝트 폴더·일 폴더·설정·훅·설치본·상주 처리기 |
| **프로젝트 폴더** | `projects/{프로젝트}/` — 일을 넘어 이어지는 것. `state/`: 상태(「닫힘」·「열림 {일 이름}」·「복구 중 {일 이름}」), **마지막 처리 번호**, **마지막 케이스 수**(지적 케이스·장면 케이스 따로), `queue.md`(훅이 만드는 표시). `records/원문.jsonl`: 대표 메시지와 제시 줄, **프로젝트 단위 일련번호**. `도면.md`, `일지.jsonl`(덧붙이기만), `archive/`(닫기·포기 보관본). 적용 목록 승인이 이 폴더와 「닫힘」을 만든다 |
| **일 폴더** | 하네스 홈의 `jobs/{프로젝트}/{일 이름}/`(작업 트리·저장소 밖) — 그 일만의 것. `outputs/`(산출물, 주인 표), `requests/{직원}/{번호}.md`(요청, 직원별 폴더라 번호가 겹치지 않음), `records/`(실행·열람·편집 기록, `records/probe/` 실측 로그, **`records/requests/{직원}/{번호}.result`** 요청 결과 — 직원 쓰기 불가 폴더라 이름 규칙에 기대지 않음), `gates/`(bench.json·검토 지문·시험대 지문), `snapshots/`(일 시작·칸 시작 사본). 지적에서 자동으로 열리는 일의 이름은 `지적-{번호}` |
| **산출물 주인** | `outputs/facts.md` 사실확정자 · `outputs/plan.md`·`outputs/tools.md` 계획자 · `outputs/design/`(폴더) 시안자 · `outputs/coverage-{구현자}.md` 각 구현자(처리기가 합침) · `outputs/review.md` 검토자 · `outputs/report.md` 반장(편집 도구로 이 파일만). 그 밖의 쓰기: 구현자 = plan.md 소유표에 자기 이름으로 배정된 작업 트리 파일(plan.md 자체는 쓰지 못함), 시험자 = `tests/bench/`(번호 이름), 실측자(소형 궤도에서는 계획자) = `scripts/probe/`(스크립트만, 실행과 로그는 요청·기록). 요청 파일은 각자 자기 폴더 |
| **쓰기 창** | 주인이라도 **자기 칸에서만** 쓸 수 있다: 시험자 ⓪(케이스)·③(scenes만, 명령 오류 되돌림 때도 같음), 사실확정자 ①, 실측자 ②, 계획자 ③(과 명령 오류 되돌림), 시안자 ④, 구현자 ⑤, 검토자 ⑥, 반장 ⑧. 칸이 넘어가면 편집 도구와 샌드박스 쓰기가 함께 닫힌다. ⑥→⑤ 되돌림은 구현자 창을 다시 연다. **소형 궤도에서는 ①②가 따로 열리지 않는다**: 계획자가 ③에서 사실확정 절과 실측 절을 함께 쓰고, `scripts/probe/` 쓰기와 실측 실행 요청도 이 궤도에서는 계획자가 ③에서 한다 |
| **허용 경로** | 「산출물 주인」 × 「쓰기 창」. **샌드박스 쓰기 허용 = 편집 도구 허용 = 이 교차.** 누구도 소유할 수 없는 것: 의존성 폴더, **모든 깊이의 `.gitignore`(새로 만들기 포함)**, 패키지 목록(manifest)과 잠금 파일(설치 요청으로만 바뀜), 시험 설정 파일·`conftest.py`, 링크 파일, 하위 저장소 |
| **제외 목록** | 설정의 세 가지: 의존성 폴더, 빌드 산출물, `.claude/`. 적용 등록 때 추적 중인지 검사해, 추적 중이면 (가) 추적 해제 (나) 「배포 산출물 경로」 등록 중 택일. `.claude/`가 추적 중이면 설정 변경은 승인 관문이 승인 번호를 메시지에 적어 따로 커밋하며, **「닫힘」에서 승인되면 승인 관문이 바로 적용·커밋하고, 「열림」·「복구 중」·「닫는 중」에서 승인되면 기록만 하고 닫기·포기 마무리 단계에서 처리기가 「미뤄 둔 승인 커밋」으로 친다**(「보호 파일 — 설정」). 지문의 `.claude/` 항목은 그때의 HEAD에서 옮기며, 일이 열린 동안에는 이 커밋이 없으므로 세 지문 사이에 이 항목이 바뀌지 않는다 |
| **커밋 트리 범위** | `.gitignore`를 따르는 범위(추적 + 무시되지 않은 미추적) − 제외 목록. 계산은 **전역 무시 설정과 `.git/info/exclude`를 끈 상태**로 고정(컴퓨터가 달라도 같은 범위). 범위 안에 **작업 트리 밖을 가리키는 링크 파일이나 하위 저장소가 있으면 지문 계산을 거부**하고 칸을 멈춘다. 이 하나의 범위가 지문·사본·실행 사본·검토자 사본·비교·복원·소형 재판정·보관 전부의 범위 |
